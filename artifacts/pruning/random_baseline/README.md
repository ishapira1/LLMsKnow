# `random_baseline`

This directory contains the verified lightweight core-complete release:
machine-readable summaries, seed-level tables, Pareto figures, provenance, and
the generated LaTeX subsection. Raw generations and masks remain under Harvard
storage at `LLMsKnow_results/random_baseline`.

The design was fixed before results in `preregistration.json`. The full
confirmatory core completed for all 80 random controls and supports
weight-selection specificity for both models. The user then authorized a
resource-saving stop because random-mask effects remained close to base. The
already-running 12-state Llama SycoBench block was retained and audited; 132
unstarted broad states and feedback judging were explicitly omitted.

The authoritative alternative acceptance record is
`early_stop_completion_audit.json` (logical audit SHA-256
`7da20613e29f831e5a0c416ac8f1998a353ea1c4fbe52677d6563234a8899316`).
It verifies 80 masks, 84 core states, 1,077,594 core rows, 12 supporting broad
states, 21,600 supporting rows, six archived milestone receipts, and the exact
scheduler cancellation. It does not claim that the original full broad-suite
or judging acceptance gate completed.
